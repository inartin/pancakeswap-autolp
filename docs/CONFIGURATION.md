# Configuration

Environment variables, API keys, and database setup.

## Environment Variables

All variables live in `.env` (created by `pnpm run setup` from `.env.example`).

### Required

```bash
TELEGRAM_BOT_TOKEN=your_bot_token_here          # From @BotFather
TELEGRAM_ADMIN_ID=your_telegram_user_id         # From @userinfobot
SOLANA_RPC_URL=https://your-rpc-endpoint.com    # Helius recommended
MASTER_PASSWORD=...                             # Auto-set by `pnpm run setup`
```

### Runtime

- `NODE_ENV` — `development` (default) or `production`
- `LOG_LEVEL` — `info` (default) or `debug`

### Production database

Required when `NODE_ENV=production`:

- `POSTGRES_URI=postgresql://user:pass@host/db`

### API keys (recommended)

- `JUP_API` — Jupiter API key (https://portal.jup.ag/)
- `JUP_PLAN` — `free` or `paid` (default: `free` in `.env.example`)
- `MORALIS_API_KEY` — Token metadata lookups (https://moralis.io/)

### Jupiter tuning (optional)

- `JUPITER_API_BASE_URL` — Default `https://api.jup.ag/swap/v1`
- `JUPITER_ULTRA_API_BASE_URL` — Default `https://api.jup.ag/ultra/v1`
- `JUPITER_PRIORITY_FEE_LAMPORTS` — Default `1000000` (~0.001 SOL), cap `30000000`

### Transactions (optional)

- `USE_SWQOS` — Use Helius SWQOS for higher success rate (default `true`)
- `TX_METADATA_PARSE_MAX_RETRIES` — Default `3`
- `TX_METADATA_PARSE_RETRY_DELAY_MS` — Default `1000`

### Redis cache (optional)

Speeds up static lookups (decimals, token programs, metadata).

- `USE_REDIS` — Default `false`
- `REDIS_HOST`, `REDIS_PORT`, `REDIS_PASSWORD`, `REDIS_DB`

### Claim split (optional)

- `SPLIT_CLAIM_PERCENT` — Fraction (0–1) of claimed rewards transferred to a configured claim address. Default `0.75`.

### Rebalance top-up (optional)

- `REBALANCE_TOP_UP_ENABLED` — Default `true`
- `REBALANCE_TOP_UP_MIN_UTILIZATION` — Default `0.5`
- `REBALANCE_TOP_UP_DUST_USD` — Default `1`

### Ethereum (optional, read-only Uniswap views)

- `ETH_RPC_URL` — e.g. `https://ethereum-rpc.publicnode.com`

## API Keys

### Helius (RPC)

The bot uses Helius's Priority Fee API to set optimal transaction fees. Other RPC providers fall back to safe (slower, more expensive) values.

Free API key: https://www.helius.dev/

### Jupiter

Used for token swaps (compounding, rebalancing). The API key enables dynamic rate limits and prevents 504 Gateway Timeout errors.

1. Sign in at https://portal.jup.ag/
2. Generate API Key (universal — works for all Jupiter APIs)
3. Paste into `JUP_API`

### Telegram

**Bot token:** Message [@BotFather](https://t.me/botfather), send `/newbot`, follow prompts, copy token into `TELEGRAM_BOT_TOKEN`.

**Your user ID:** Message [@userinfobot](https://t.me/userinfobot), copy the numeric ID into `TELEGRAM_ADMIN_ID`.

## Master Password

`MASTER_PASSWORD` encrypts all wallet private keys in the database.

- Auto-generated by `pnpm run setup` using cryptographically secure random bytes (256-bit)
- **Never** share or commit this password
- **Never** lose this password (keys cannot be recovered without it)
- Backup your `.env` file securely
- Already gitignored

If you need to regenerate manually:

```bash
openssl rand -base64 32
```

## Database

### Development mode

Uses SQLite locally at `data/autofarmer.db`. Fully automated — no setup required.

### Production mode

Uses **dual-database storage**:

- **SQLite** — Local primary database
- **Postgres** — Cloud backup (wallets only)

Critical data (wallets) is stored in both databases for redundancy. If one fails, the other still has the data.

```bash
# Development (default)
NODE_ENV=development    # SQLite only

# Production
NODE_ENV=production     # SQLite + Postgres
POSTGRES_URI=postgresql://user:pass@host/db
```

### How it works

- Schema defined in `src/db/schema.js` (source of truth)
- Migrations auto-apply on startup
- Production: writes to both databases atomically
- Development: writes to SQLite only

### Making schema changes

```bash
# 1. Edit src/db/schema.js
# 2. Generate SQLite migration
pnpm db:generate

# 3. If changing the wallets table, update src/db/postgres-schema.js
#    and generate the Postgres migration:
pnpm drizzle-kit generate --config=drizzle-postgres.config.js

# 4. Restart the bot (migrations auto-apply)
pnpm start
```

### Tools

```bash
pnpm db:studio    # Visual database browser (SQLite)
```
